## 1. 引言

### 1.1 编写目的
本文档针对"科协优阅网"进行完整的需求分析，明确系统的功能边界、用户角色、数据模型、页面规格、接口约定与非功能约束，作为后续设计、开发、测试与验收的依据。

### 1.2 项目背景
计算机工程学院科学创新技术协会（简称"科协"，英文 Scientific Innovation and Technology Association，SITA）长期组织学生参加蓝桥杯、华为 ICT 大赛、全国大学生信息安全竞赛、睿抗机器人开发者大赛、天梯赛等各级学科竞赛。随着参赛规模与获奖数量的快速增长（当前已沉淀 **168 项**获奖成果），成果信息分散、展示渠道有限、赛事组织依赖人工统计等问题日益突出。

为此需要建设一个**以竞赛成果展示为核心、兼顾赛事组织与协会宣传**的综合门户平台，实现：
- 历届获奖成果的**数字化归集与结构化展示**；
- 年度赛事的**规划、报名与风采记录**；
- 协会组织、榜样人物、经验文章的**统一宣传阵地**；
- 面向会员的**注册登录与个人成果维护**能力；
- 面向管理员的**内容维护后台**。

### 1.3 术语定义
| 术语 | 说明 |
| --- | --- |
| 成果 / 证书 | 学生在各级竞赛中获得的获奖记录，含证书图片 |
| 赛事级别 | 全球级 / 国家级 / 省级 / 市级 / 校级 / 其他 |
| 获奖等级 | 特等奖 / 一等奖 / 二等奖 / 三等奖 / 金奖 / 银奖 / 铜奖 / 优秀奖 / 其他 |
| 赛事规划 | 年度内计划参加或举办的赛事及其时间安排（甘特图/时间轴） |
| 赛事报名 | 由协会发起的校内外赛事，支持在线报名 |
| 赛事风采 | 赛事现场照片集（图库） |
| 作品 | 学生参赛作品、毕业设计、软硬件作品 |
| 榜样力量 | 优秀学长学姐等榜样人物介绍 |

### 1.4 参考依据
- 目标站点 youyue.info 现有页面与数据结构（导航、筛选维度、卡片字段、接口返回）；

## 2. 系统概述

### 2.1 系统定位
一个面向**学院师生 + 协会管理员 + 社会访客**的学科竞赛成果门户。前台以"展示"为主、以"参与"为辅；后台以"内容维护"为主。

### 2.2 总体架构
```
┌──────────────────────────────────────────────────────────┐
│                        表现层 (View)                       │
│  首页 / 竞赛成果 / 赛事规划 / 赛事报名 / 赛事风采 /         │
│  作品展示 / 榜样力量 / 协会组织 / 文章 / 会员中心 / 管理后台 │
├──────────────────────────────────────────────────────────┤
│                     控制层 (Controller)                    │
│  路由分发 · 参数校验 · 权限拦截 · 查询筛选 · 模板渲染        │
├──────────────────────────────────────────────────────────┤
│                      服务/数据层 (Model)                   │
│  成果服务 · 赛事服务 · 图库服务 · 作品服务 · 用户服务 ·       │
│  文章服务 · 统计服务                                        │
├──────────────────────────────────────────────────────────┤
│                    SQLite 数据库（持久化）                  │
└──────────────────────────────────────────────────────────┘
```

### 2.3 技术选型（实现约束）
| 层面 | 选型 | 说明 |
| --- | --- | --- |
| 运行环境 | Node.js | 服务端运行时 |
| Web 框架 | Express | 路由与中间件 |
| 模板引擎 | EJS | 服务端渲染，利于 SEO |
| 数据库 | SQLite（node:sqlite） | 零依赖、单文件、便于部署 |
| 会话 | Cookie + 内存 Session | 登录态保持 |
| 前端 | 原生 HTML5 / CSS3 / ES6 | 无框架依赖，兼容性好 |
| 素材 | 自研 SVG 占位图生成 | 不依赖外部图床，离线可用 |

> 需求方原系统为 PHP + MySQL 实现。本次按"需求一致、可独立运行"的原则，采用 Node.js 技术栈重新实现，功能与页面结构对齐原站。

### 2.4 运行环境
- 现代浏览器：Chrome / Edge / Firefox 最新两个大版本；
- 服务端：Node.js 18+（推荐 22 LTS）；
- 数据库：单文件 `data/youyue.db`；
- 静态资源：本地 `public/` 目录。

## 5. 数据模型

### 5.1 E-R 关系概述
```
管理员(admin)        ── 管理 ──▶  全部内容实体
会员(member)         ── 提交 ──▶  成果(certificate)
竞赛分类(category)    ◀── 归属 ──  成果(certificate)
赛事规划(event_plan) ── 关联 ──▶  竞赛分类(可选)
赛事(competition)    ── 报名 ──▶  报名记录(registration) ◀── 会员(member)
图库(gallery)        ── 包含 ──▶  图库照片(gallery_image)
作品(work) / 榜样(role_model) / 组织(org_member) / 文章(article)
```

## 8. 非功能需求

### 8.1 性能
- 首屏（首页）渲染时间 ≤ 2s（本地环境）；
- 成果列表分页加载，单页 20 条，避免一次性渲染全部数据；
- 图片懒加载，仅加载视口内资源。

### 8.2 兼容性
- 响应式布局：适配 PC（≥1280）、平板（768–1279）、手机（<768）；
- 移动端提供汉堡菜单、卡片单列、触摸滑动查看证书。

### 8.3 安全性
- 密码使用加盐哈希存储（`scrypt`），不存明文；
- 登录态使用 HttpOnly Cookie；
- 所有数据库访问使用参数化查询，防止 SQL 注入；
- 模板渲染对用户输入做 HTML 转义，防止 XSS；
- 后台接口做登录态校验，未登录一律跳转登录页。

### 8.4 可用性与体验
- 统一的视觉规范（主题渐变色 `#667eea → #764ba2`，卡片圆角阴影）；
- 所有空数据、错误场景有友好提示；
- 交互反馈：按钮 hover、卡片悬浮、加载状态。

### 8.5 可维护性
- 前后端分离的目录结构；模板组件化（头部/页脚复用）；
- 数据与代码分离，通过 `data/seed.json` 初始化；
- 统一的路由与控制器组织。

### 8.6 部署约束
- 单机可运行，`npm install && npm start` 即可启动；
- 无外部服务依赖（图片、字体均本地化）。
